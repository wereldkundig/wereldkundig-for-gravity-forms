---
title: Capabilities
description: Which capabilities give access to the Wereldkundig settings, feeds and uninstalling.
---

The add-on has its own capabilities, so you can grant them separately, for example with the Members plugin. Users with `gform_full_access`, such as administrators, pass every check.

| Capability | Allows |
|---|---|
| `gravityforms_wereldkundig` | The Wereldkundig settings page, and the link to it in the form editor's notices. |
| `gravityforms_wereldkundig_uninstall` | Uninstalling the add-on from Gravity Forms. |
| `gravityforms_edit_forms` (Gravity Forms) | Wereldkundig feeds under **Form Settings**. |
