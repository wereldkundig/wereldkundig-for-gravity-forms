## How it works

<CardGrid>
	<Card title="Connect" icon="setting">
		Enter the platform URL and the Basic Auth code supplied by Wereldkundig under **Forms > Settings >
		Wereldkundig**.
	</Card>
	<Card title="Add the checkbox field" icon="pencil">
		Add a **Wereldkundig subscribe me** field to a form. Then add a feed that chooses that checkbox,
		checks the themes (or only some of their categories) and maps the Email field.
	</Card>
	<Card title="Visitors subscribe" icon="rocket">
		When the checkbox is checked, their email address and the other mapped fields are sent to Wereldkundig. The entry gets a note with the result.
	</Card>
	<Card title="Go further" icon="puzzle">
		Map more fields in the feed, add conditional logic, or change what is sent with filters.
	</Card>
</CardGrid>

## Requirements

WordPress 6.9+, PHP 8.2+ and Gravity Forms 2.5+. Works on single sites and on multisite networks.
